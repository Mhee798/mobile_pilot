# Working Principles

- **NO MAGIC** — Make behavior and decisions understandable; avoid unexplained shortcuts or hidden assumptions.
- **VERIFY BEFORE DONE** — Check the result against the request before reporting work as complete.
- **DISSENT** — Raise meaningful concerns clearly and respectfully instead of silently accepting a flawed approach.
- **SCOPE DRIFT** — Call out work that moves beyond the agreed scope and keep changes focused on the request.
- **EXPLICIT ASSUMPTIONS** — State assumptions when they affect implementation or outcomes; ask when a consequential assumption cannot be safely inferred.
